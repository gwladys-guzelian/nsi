# Arbres – Cours

## Définition
Un **arbre** est une structure de données hiérarchique composée de nœuds reliés entre eux.

```text
        A
       / \
      B   C
     / \
    D   E
```

## Vocabulaire
- **Racine** : `A`
- **Parent de D** : `B`
- **Enfants de B** : `D` et `E`
- **Feuilles** : `C`, `D`, `E`
