# Paradigmes et techniques de programmation

| Paradigme | Idée principale |
|-----------|-----------------|
| Impératif | Exécuter des instructions qui modifient l'état du programme. |
| Orienté objet | Organiser le programme autour de classes et d'objets. |
| Fonctionnel | Transformer des données avec des fonctions en limitant les effets de bord. |

## Techniques
- Itération : boucles.
- Récursivité : une fonction s'appelle elle-même.
- Procédural : organisation en fonctions/procédures.
